# 배달이익노트

**배민 주문 1건마다, 실제로 얼마가 남는지** 보여 주는 사장님용 도구입니다.
주문마다 드는 중개이용료·결제수수료·배달비·광고비를 주문 1건 기준으로 쪼개 보여 줘서, 매출 장부로는 잘 안 보이는 "진짜 남는 돈"을 알 수 있습니다.

## 1. 자료 없이 먼저 써 보기 (1분)

1. https://baemin-profit-note-demo.vercel.app 을 엽니다. (로그인 없이 바로 눌러 보는 가상 데이터 데모. 위쪽 "여기부터 눌러 보세요"를 따라가면 됩니다)
2. **"자료 없이 예시 화면 먼저 구경하기"** 를 누릅니다.
3. 위쪽 "가게"에서 예시 가게를 바꿔 봅니다.
   - **A** — 모든 값이 채워진 예 (한눈에 보기 좋음)
   - **B** — 값이 덜 채워진 예 (포장비·인건비가 비어 있으면 화면이 뭐라고 하는지)
   - **C** — 정산·광고 자료까지 있는 예 (메뉴별 남는 돈, 입금 대조, 광고 효율)
4. **간단히 보기**(처음 화면)와 **자세히 보기**(원가·가격 실험·월별 비교·엑셀)를 오가 봅니다.

예시 가게의 숫자는 **전부 처음부터 만든 가상 숫자**입니다. 어느 실제 가게의 자료도 아닙니다.

## 2. 내 가게 숫자로 보기 (내 컴퓨터에서)

내 가게 숫자는 **내 컴퓨터에서만** 볼 수 있습니다. 인터넷 사이트에는 올라가지 않습니다.

1. 설치 파일(`배달이익노트.zip`)을 받아 압축을 풀고 `baemin-profit-note-start.bat` 을 더블클릭합니다. (직접 만들려면 아래 "개발자용")
2. 브라우저가 열리면 **"자료 가져오기"** 를 누릅니다. 크롬이 열리면 **배민에 직접 로그인**합니다. 5~10분 걸립니다.
3. **처음 설정**을 따라 재료비·포장비·인건비·월세를 넣습니다. 재료비는 "%"를 몰라도, 대표 메뉴 한 그릇의 판매가와 재료비만 알면 됩니다.

## 안전

- **배민 비밀번호는 배민 화면에만 입력**되고, 이 프로그램은 저장하지 않습니다.
- **읽기만** 합니다. 메뉴·가격·광고 설정은 바꾸지 않습니다.
- 가져온 자료는 내 컴퓨터의 `data/` 폴더에만 저장되고 어디로도 보내지 않습니다. (`data/`는 git·배포에서 제외)
- 수집 방식: 배민 주문내역 화면이 스스로 보내는 조회 요청의 **기간·건수만 바꿔** 같은 화면을 다시 부르고 응답을 받아 적습니다. 접근 제한을 우회하지 않습니다.

## 무엇을 계산하나

| 단계 | 뜻 |
|---|---|
| 수수료·재료비 뺀 돈 | 주문 1건을 팔면 들어오는 돈에서 그 주문 때문에 나가는 돈(중개이용료·결제수수료·배달비·재료·포장)을 뺀 것 |
| 광고비까지 뺀 돈 | 거기서 광고비 같은 배민 전용 비용을 뺀 것 |
| 진짜 남는 돈 | 거기서 인건비·월세 중 배민 몫까지 뺀 것 |

- 입력하지 않은 비용은 **0원으로 치지 않고 "입력 필요"** 로 표시합니다. 자료가 없는 날도 0원으로 채우지 않습니다.
- 그 밖에: 가격 실험(메뉴 하나만 올리면?), 손익분기 주문 수, 메뉴별 남는 돈, 광고 효율, 정산 대조(입금 전은 빨갛게), 엑셀·인쇄, 개선 추천(계산식 기반).

## 지금 안 되는 것

- 자료 수집은 내 컴퓨터에서만 됩니다. (배민 로그인이 필요해서 인터넷 서버로는 못 합니다)
- 배민 화면이 바뀌면 수집이 멈출 수 있습니다.
- 최근 며칠 주문은 배민 정산 전이라 빠집니다 (몇 건 빠졌는지 화면에 표시).
- 부가세·소득세 조정 전 금액입니다.
- AI 추천은 아직 없습니다 (지금은 정해진 계산식).

## 데모 사이트 따로 만들기 (공유회·배민아카데미용)

같은 저장소로 새 Vercel 프로젝트를 만들고, **Environment Variables에 `NEXT_PUBLIC_DEMO_SITE` = `1`** 을 넣어 배포하면 로그인 없이 바로 눌러 볼 수 있는 가상 데이터 데모가 됩니다. 이 변수가 없는 배포는 지금처럼 동작합니다.

## 개발자용

```bash
npm install
npm run dev        # http://localhost:3500
npm test           # 계산 엔진 테스트 (PRD 12장 예시 숫자 포함)
npm run package    # dist/배달이익노트.zip (PC 설치 꾸러미)
```

- `src/lib/engine` — 순수 계산 (원화는 정수, 비율·배분은 분수). `src/lib/dataset.ts` — 일별 자료 집계. `src/lib/demo.ts` — 가상 예시 가게. `src/components` — 화면.
- `scripts/` — 자료 수집·정리, 설치 꾸러미 만들기. 기획서는 [docs/PRD.md](docs/PRD.md), 변경 이력은 [CHANGELOG.md](CHANGELOG.md), 가상 사장님 QA·검토 기록은 `docs/qa-*.md`.
