## 잘 된 것 (건드리지 말 것)

- **"배민에 로그인만 해 주시면 … 알아서 읽어 옵니다"** — 박은하가 망설임 없이 누른 이유.
- **"비밀번호는 배민 화면에만 입력되고 저장하지 않아요"** — 장승옥의 불안을 반쯤 풀었음.
- **"주문 1건당 남는 금액"** 카드 — 세 명 중 도달한 두 명 모두 바로 이해.
- **"공제 중 배달 비용이 가장 커요: 주문당 2,450원"** — 장승옥이 "장부로는 이게 안 보였다"며 쓸 이유를 찾은 문장(수락 신호).
- 포장비 칸의 **"용기·비닐·젓가락처럼"** 예시, 원가율의 **"대충 35처럼 넣고 나중에 고치면"** 문장.
- 메뉴별 수익성의 **"개당 10,000원"**, **"원가 순서대로 넣기"**.
- 압축을 안 풀었을 때 검은 창의 한국어 안내 — 김상희가 이걸 보고 다시 해냈음.

## 먼저 고칠 것

1. **(S1) 재료원가율을 몰라도 시작할 수 있게** — 대표 메뉴 한 개의 판매가·재료비로 원가율 계산.
2. **(S2, 오해) 처음 켰을 때 가짜 숫자 대신 '자료 가져오기' 안내** — 데모는 "예시 보기"로 숨기고 내부 이름 삭제.
3. **(S2) 용어를 사람 말로** — 공헌이익·직접비·잔여액·수수료 가정 등, 물음표 설명 추가.
4. **(S2) 수집 진행을 사람 말로** — 진행 막대·남은 시간·"크롬 닫지 마세요".
5. **(S2) 안심 문구·입력칸 위치** — "이 PC에만 저장"을 화면에, 인건비·월세 칸을 4단계 안으로.

## 이번 QA가 확인하지 못한 것

- 실제 배민 로그인·인증 과정 (각자 계정이 필요 — 문서 기준으로만 봄)
- Windows 보안 경고의 실제 문구 (PC·설정마다 다름)
- 모바일 화면 (PC 프로그램이라 제외)
- 실제 사장님들의 반응 — 배포한 사장님들께 직접 물어볼 질문: **"처음 켰을 때 무엇을 해야 할지 바로 알았나요? 재료원가율을 바로 넣을 수 있었나요?"**
