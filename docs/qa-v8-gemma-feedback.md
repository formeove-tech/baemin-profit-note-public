## 3. 고친 뒤 확인

- 폰 폭 375px: 예시 가게 A·B·C 모두 간단히 보기·자세히 보기에서 옆으로 밀리지 않음. 작은 버튼은 체크박스(글자째 눌림)만 남음.
- 처음에 짚은 원인(선택 칸)은 틀렸고, 고치기 전·후 수치가 같아서 알았다. 진짜 원인은 표가 든 칸이 줄어들지 못하던 것(`grid-cols-1`로 해결).
- 예시 가게 C: 광고비 삭제 버튼 120개 → 1개, 정산 대조에 '아직 입금 전' 합계와 빨간 줄.
- `npm run typecheck`, 테스트 35개 통과 (C의 판매액=메뉴 합, 같은 날 두 번 만들어도 같음, 실제 이름 없음 등 6개 추가).
- 패드(터치) 크기는 `pointer: coarse` 조건으로 적용되며, 실제 패드에서는 아직 못 봤다. 공유회 전에 한 번 확인 필요.
