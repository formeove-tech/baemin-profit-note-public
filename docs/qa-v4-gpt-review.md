## GPT가 못 본 것 (예시 화면의 한계)

- "첫 입력부터 원가율 %를 요구" — v3의 '대표 메뉴 한 그릇 재료비'는 실제 자료가 있을 때만 나왔다.
  → v4: 예시 가게에서도 처음 설정을 보여 주고, '원가와 비용'의 % 칸에도 한 그릇으로 계산하는 도우미를 붙였다.

## 미룬 것

- 업종별 계산: 치킨(본사 가격 정책), 카페(한 주문에 여러 잔 → 잔당 인상), 분식(용기 수). 계산 방식 변경이 필요.
- '가져온 자료 기간'과 '보고 싶은 기간'을 붙여 보여 주고 부족한 기간을 바로 가져오는 버튼.
- 기본 화면을 '매출 / 빠진 돈 / 남는 돈 / 확인할 것 1개'로 줄이고 상세는 펼치기.
